- Session history remains in `<workspace>/.tura/session_log.sqlite3`.
- Interrupted turns may appear as `interrupted` or `error`; the conversation can
  still accept another prompt.
- Install desktop builds from GitHub Release assets, not npm platform packages.
- Provider settings now display masked secrets.
