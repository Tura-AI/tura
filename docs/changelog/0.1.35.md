# Tura 0.1.35

Released on 2026-07-28. Changes are relative to
[`v0.1.34`](https://github.com/Tura-AI/tura/releases/tag/v0.1.34).

## Highlights

- Preserved final assistant responses when the TUI hands a completed command
  back to scrollback, including cached transcript rendering. This fixes
  [issue #25](https://github.com/Tura-AI/tura/issues/25) and was integrated by
  [pull request #28](https://github.com/Tura-AI/tura/pull/28).
- Prevented the gateway from replaying an enqueue request after the caller has
  already timed out, avoiding duplicate work during timeout recovery.
- Migrated the Rust workspace to Edition 2024, updated Unix FFI declarations,
  and restored the repository rustfmt policy used by CI.
- Hardened npm release and recovery publishing by fixing artifact paths and
  retrying registry propagation checks.

## Upgrade notes

- No session database migration is required.
- The npm package continues to support Node.js 20 and newer.
- The public npm package remains `tura-ai`; native platform packages are
  selected through optional dependencies at the same version.
